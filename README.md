# Business Intelligence and Analytics Using Microsoft Power BI — Companion Files

*From Data to Decisions: A Hands-On Guide for Management Students* — Dr. Ramesh Kandela

This repository holds the datasets used in the hands-on laboratories of the book.
No GitHub account is needed to download them.

## How to download

- **All files at once:** click the green **Code** button, then **Download ZIP**. Unzip the file into a folder such as `Documents\PowerBI_Labs`.
- **One file:** open a chapter folder, click the file name, then click the **Download raw file** button.
- **Directly in Power BI:** open a CSV file, click **Raw**, copy the address from the browser and paste it into **Get data > Web**.

Keep the file names unchanged, because the lab steps refer to them by name.
